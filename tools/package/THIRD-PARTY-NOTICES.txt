Il2CppInterop 1.5.3 (BepInEx/core/Il2CppInterop.Common.dll, BepInEx/core/Il2CppInterop.Runtime.dll)
  BepInEx team, knah et al., Pietrodjaowjao - LGPL-3.0 (licenses/LGPL-3.0.txt, licenses/GPL-3.0.txt)
  https://github.com/BepInEx/Il2CppInterop
  This is a modified build (modified by TownOfHost_L, 2026-11-14). It is built from
  https://github.com/Pietrodjaowjao/Il2CppInterop/commit/f1627d60efc218e4861bacc1239267f96f32ee2c
  (a fork of BepInEx/Il2CppInterop that adds the GC write barrier for field stores) with
  tools/Il2CppInterop/il2cppinterop.patch in the TownOfHost_L source repository applied: MemoryUtils calls
  VirtualQuery without TerraFX.Interop.Windows, the memory region walk and the signature scan stop on empty
  or unreadable input, and Class_FromIl2CppType_Hook passes a null type to the original function.
  TownOfHost_L further modifies Il2CppInterop.Runtime.dll so that three reference stores go through the
  game's GC write barrier (il2cpp_gc_wbarrier_set_field): IL2CPP.FieldWriteWbarrierStub,
  Il2CppReferenceArray<T>.StoreValue and the Il2CppStringArray indexer setter. It also adds
  IL2CPP.WbStore(IntPtr, IntPtr). This step is done by tools/InteropWbPatch in the TownOfHost_L source
  repository. tools/package.ps1 shows the whole build. The built files report the version
  1.5.3+f1627d60.tohl.
  You may replace these files with any other compatible build of Il2CppInterop.
