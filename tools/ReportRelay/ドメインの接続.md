# 自分のドメインで中継 (tohl-report-relay) を動かす (Cloudflare)

`npx wrangler deploy` した中継は、そのままでも `https://tohl-report-relay.<アカウント名>.workers.dev` で動きます。
これを `https://relay.example.com` のような自分のドメインで受けるようにする手順です。
(`example.com` は自分のドメイン、`relay` は好きな名前に読み替えてください)

---

## 1. ドメインを Cloudflare に入れる

**もう Cloudflare でドメインを管理している (Cloudflare Registrar で買った・前に追加した) なら、2. へ。**

他の所 (お名前.com・Google Domains / Squarespace・ムームードメインなど) で買ったドメインの時:

1. https://dash.cloudflare.com にログイン
2. 左の「ドメインの追加 (Add a domain)」→ `example.com` を打つ → 続行
3. プランは **Free** を選ぶ
4. DNS の記録の読み込みが出たら、そのまま続行 (メールなどで使っている記録があれば消さない)
5. **ネームサーバー 2 つ** (例: `xxx.ns.cloudflare.com` と `yyy.ns.cloudflare.com`) が出るので控える
6. ドメインを買った所の管理画面で、ネームサーバーを「その他 / カスタム」にして、控えた 2 つに書き換える
   - 元のネームサーバーは全部消して、Cloudflare の 2 つだけにする
   - DNSSEC を有効にしていたら、先に買った所で切っておく (切らないと繋がらない)
7. Cloudflare に戻り「ネームサーバーを確認 (Check nameservers)」
8. ドメインの状態が **有効 (Active)** になるまで待つ (数分〜最大 24 時間。Cloudflare からメールが来る)

---

## 2. Worker にドメインを付ける

どちらか片方で OK です。

### A. 画面から (簡単)

1. Cloudflare の左「Workers & Pages」→ `tohl-report-relay` を開く
2. 「設定 (Settings)」→「ドメインとルート (Domains & Routes)」→「追加 (Add)」
3. 「カスタムドメイン (Custom domain)」を選び、`relay.example.com` を打って追加
4. DNS の記録と証明書 (HTTPS) は Cloudflare が自動で作る。数分で「有効」になる

### B. wrangler.toml に書く (作り直しても消えない)

`wrangler.toml` の `[vars]` より上に足して、デプロイし直す:

```toml
routes = [
  { pattern = "relay.example.com", custom_domain = true }
]
```

```powershell
npx wrangler deploy
```

> 注意: `relay.example.com` に同じ名前の DNS の記録 (A / CNAME) が既にあると追加できません。
> Cloudflare の「DNS」→「レコード」で、その名前の記録を消してからやり直してください。

---

## 3. 繋がったか確かめる

ブラウザで `https://relay.example.com/` を開き、次のように出れば OK:

```json
{"ok":true,"service":"tohl-report-relay"}
```

PowerShell なら:

```powershell
Invoke-RestMethod https://relay.example.com/
```

- 「この サイトにアクセスできません」: ドメインがまだ有効になっていない / DNS の反映待ち。少し待つ
- 証明書のエラー: 証明書の発行待ち (最大 15 分ほど)
- `{"ok":false,"error":"not_found"}`: 繋がってはいる。URL の最後の `/` 以降が違うだけ

---

## 4. MOD を新しいドメインへ向ける

`Modules/BugReport.cs` の `DevRelayUrl` に新しいドメインを入れて、ビルドし直す:

```csharp
const string DevRelayUrl = "https://relay.example.com";
```

(最後に `/report` は付けない。MOD が自分で付ける)

`workers.dev` の URL もそのまま動き続けます。使わないなら、Worker の「設定」→「ドメインとルート」で `workers.dev` を無効にできます。

---

## よくあること

| 困ったこと | 直し方 |
|---|---|
| ドメインがずっと「保留中 (Pending)」 | 買った所のネームサーバーが Cloudflare の 2 つだけになっているか見る。DNSSEC を切る |
| カスタムドメインを追加できない | 同じ名前の DNS の記録を消す。ドメインが Cloudflare で有効になっているか見る |
| `example.com` そのもの (サブドメイン無し) で使いたい | 2. で `example.com` を打てば使える。ただしサイトなど他で使っているなら `relay.` などのサブドメインがおすすめ |
| 費用 | ドメイン代だけ。Workers の無料枠 (1 日 10 万回) で足りる |
