# TownOfHost-L

## TownOfHost-Lへようこそ！
### よくある質問
- 公開ルームは使えるの？
  - 使えます。公式サーバーでは、TOH_L の部屋に Mod の部屋であることを示す印 (Mod GUID) を付けて立てます。
  - TOH_L を入れた人が「ゲームを探す」で部屋を探すと、初期設定では TOH_L の部屋だけが表示されます。クライアント設定の「TOH_Lの部屋だけ表示」を切ると、ほかのモッド部屋も探せます。
  - バニラ（モッドなし）のプレイヤーも、部屋コードで TOH_L の部屋に入れます。

- 役職の説明はどこを見ればいい？
  - ゲーム内の役職辞典や、チャットのヘルプコマンド (`/h` `/help`) をご覧ください。
  - 自身の役職説明が一番初めの会議にチャットで表示される設定もあります。

- マッドの道連れないの？
  - 入れるマッドを選んでから、バフ属性を付与する>>リベンジャーの選択で道連れマッドを作成できます。それ以外にもたくさんの属性を付与することで様々な能力をもたせることが可能です。

- ホスト以外も Mod を入れていい？
  - 入れても遊べます。TOH_L はホストだけが入れれば動く Mod なので、参加する人が入れる必要はありません。
  - ホストが同じバージョンの TOH_L なら、参加した人の画面にも TOH_L の表示が出ます。ロビーの設定の一覧、イントロの役職と陣営、タスクの欄の役職の説明、結果画面の全員の役職の一覧です。キルや能力のボタンの表示と、役職ごとの残り回数などはまだ本編のままです。
  - ホストと TOH_L のバージョンが違う時や、バニラ部屋（モッドなし）やほかの Mod を入れたホストの部屋では、TOH_L の機能は止まり、バニラのプレイヤーとして遊べます。つまりモッドを入れたままでも他のモッドにも参加はできます。
  - 部屋を抜けて自分で部屋を立てると、TOH_L のホストに戻ります。参加中の部屋でホストを引き継いだ場合は、その部屋では本編のホストのままです。

- ほかの Mod と一緒に入れられる？
  - 現在、本家TOH・TOH_Y を含め、ほかの Mod と同じ Among Us に一緒に入れることはできません。TOH_L だけを入れてください。

- ペットの問題は？
  - ペットを撫でて能力を使う役職があるため、試合中は生きている全員にペットが付きます (ペットを付けていない人には仮のペットが付きます)。どの役職でも同じように付くので、ペットの有無で役職は分かりません。
  - 死亡した方のペットは外れ、生存者には見えなくなります。現在のバニラの仕様とは異なりますのでご注意ください。

- TOH_Yとなにがちがうの？
  - TOH_Y の役職と機能を元に、作りを大きく組み直しています。ホストの操作盤・役職辞典・チャットの便利機能・配信向けの機能 (観客席・コメントの板・視聴者の干渉) などを足しています。
  - TOH_Y と同じ名前の役職・機能でも、挙動が変わっている所があります。

## ★見どころ: 通常の試合に、かくれんぼの鬼と懐中電灯
- **役職「バーサーカー」**: 通常モードの試合の途中で、インポスターが本編のかくれんぼの鬼の姿 (マスク姿) に変わります。Mod を入れていない参加者の画面にも鬼の姿で映ります。
- **懐中電灯モード・属性「ライティング」**: 通常モードの試合で、かくれんぼの懐中電灯の視界を出します。こちらも Mod を入れていない参加者の画面で動きます。
- どちらも、ホストだけが TOH_L を入れていれば動きます。

### English
This Readme is basically for Japanese only, and you may not be able to read it even though you came to this, sorry.<br>

We also use a translator for all in-game translations into English. If there is something wrong, please write in discord with the changed words and sentences and we may be able to help.<br>

TownOfHost-L is a host-only mod: only the host needs to install it. Players who have TownOfHost-L installed can also join other rooms. If the host runs the same version of TownOfHost-L, they see the lobby settings list, their role in the intro and the task list, and every player's role on the results screen. In any other room, the mod's features are turned off and they play as normal players. Public lobbies are supported.<br>

TownOfHost-L is a modified version of [TownOfHost_Y](https://github.com/Yumenopai/TownOfHost_Y), which is itself based on [TownOfHost](https://github.com/tukasa0001/TownOfHost). It has been modified by haru, waffle and other TownOfHost-L contributors since November 2026, and is licensed under GPL-3.0, the same as the original ([LICENSE](LICENSE)).<br>

Highlight: TownOfHost-L brings the Hide and Seek Seeker (the Berserker role) and the Hide and Seek flashlight (Flashlight Mode and the Lighting add-on) into normal-mode games, and players without the mod see them too. Only the host needs the mod.<br>

Thank you for finding and using TOH_L!<br>
